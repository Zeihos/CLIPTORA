# Подготовка публичного релиза CLIPTORA

Актуально для **0.1.15 Alpha**. Это список проверок, а не объявление готового релиза.

## Уже проверяется автоматически

- [x] Python-тесты и компиляция исходников на Windows и Ubuntu (GitHub Actions).
- [x] Сборка и тесты необязательного Rust-сканера в CI.
- [x] Проверка, что Python находит Rust-бинарник в CI.
- [x] Проверка относительных ссылок в репозитории и SVG-ресурсов.
- [x] Базовая защита локального API: проверка `Host`, `Origin` и размера JSON-запроса.

## До стабильного релиза

- [ ] Провести полный ручной тест GUI на Windows 10/11, включая установку с чистой системы.
- [ ] Подготовить и проверить подписанный (при возможности) самостоятельный Windows `.exe`/установщик.
- [ ] Проверить работу на реальной библиотеке около **250 ГБ**: время, потребление памяти, восстановление после прерывания, ошибки.
- [ ] Протестировать сохранность пользовательского проекта при обновлении/откате и переносе папок.
- [ ] Провести ручную оценку результатов автоматического монтажа по независимой разметке нескольких реальных записей.
- [ ] Проверить поведение с повреждёнными/необычными видео, отсутствие аудиодорожки, переменный FPS и длинные пути Windows.
- [ ] Проверить лицензии и распространение сторонних компонентов, включая FFmpeg, whisper-модели и Rust.
- [ ] Выпустить релиз GitHub с версией, инструкцией установки и заметками об ограничениях.

## Минимальные команды проверки

```powershell
py -3.12 -m unittest discover -s tests -v
py -3.12 -m compileall -q .
```

Для Rust: `cargo test --locked --manifest-path rust/scanner/Cargo.toml`.

Подробный сценарий ручной проверки — в [TESTING.md](TESTING.md). Пока незакрытые пункты остаются открытыми, проект честно обозначается как **Alpha**.
