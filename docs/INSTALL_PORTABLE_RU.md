# CLIPTORA Portable — версия для Windows

**Экспериментальная сборка Alpha.** Это ZIP-архив с `CLIPTORA.exe` и папкой `_internal`. Python устанавливать не нужно, но для анализа/экспорта видео требуется **FFmpeg и FFprobe**. Пока это не установщик и не стабильный релиз.

## Как скачать

1. Откройте [GitHub Actions — Windows Portable EXE](https://github.com/Zeihos/CLIPTORA/actions/workflows/windows-portable.yml).
2. Выберите последний запуск с зелёной отметкой `Success` из ветки `main`.
3. Внизу страницы скачайте **CLIPTORA-Windows-Portable** из раздела **Artifacts**. Для скачивания может потребоваться вход в GitHub.
4. Полностью распакуйте архив, **не отделяйте `CLIPTORA.exe` от папки `_internal`**.

## FFmpeg и FFprobe

Если FFmpeg уже добавлен в `PATH`, ничего устанавливать не нужно. Иначе откройте Терминал Windows и выполните:

```powershell
winget install --id Gyan.FFmpeg --exact
```

Откройте новый терминал после установки. Альтернативно поместите `ffmpeg.exe` и `ffprobe.exe` в **`tools` рядом с `CLIPTORA.exe`** (создайте папку при необходимости). Проверка:

```powershell
ffmpeg -version
ffprobe -version
```

## Запуск

Дважды нажмите `CLIPTORA.exe` и откройте `http://127.0.0.1:8765`, если браузер не запустился автоматически. **Оставьте окно консоли открытым**, пока используете CLIPTORA. Записывайте видео в отдельную папку от самой программы.

Программа использует `%USERPROFILE%\CLIPTORA` для проекта, кэша и экспортов. Исходные записи не изменяются. Предыдущие проекты открываются без ручного переноса данных. Сервер доступен только локально — **не публикуйте порт 8765 в сети**.

## Ограничения сборки

- В архив включён Rust Core для сканирования файлов; он не ускоряет FFmpeg или распознавание речи.
- **faster-whisper и его модель не включены** в базовый Portable. Распознавание речи в нём пока недоступно; для расширенного ИИ-анализа используйте [запуск из исходников](INSTALL_RU.md) с `INSTALL_AI_WINDOWS.bat`.
- Отбор сцен основан на статистических признаках, а не на гарантированном распознавании шуток. Перед публикацией проверяйте монтаж вручную.
- Сборка собирается и проверяется на Windows в GitHub Actions. Полный стресс-тест на 250 ГБ не проводился.

Если EXE не запускается, откройте Issue и приложите текст ошибки **без личных путей, фрагментов видео и токенов**.
