# CLIPTORA Portable — версия для Windows

**Экспериментальная сборка v0.1.18 Alpha.** Это ZIP-архив с `CLIPTORA.exe` и папкой `_internal`. Python устанавливать не нужно, но для анализа/экспорта видео требуется **FFmpeg и FFprobe**. Пока это не установщик и не стабильный релиз.

## Как скачать

1. Откройте [GitHub Actions — Windows Portable EXE](https://github.com/Zeihos/CLIPTORA/actions/workflows/windows-portable.yml).
2. Выберите последний запуск с зелёной отметкой `Success` из ветки `main`.
3. Внизу страницы скачайте **CLIPTORA-Windows-Portable-Core** (лёгкая версия) или **CLIPTORA-Windows-Portable-AI** (со встроенными библиотеками Whisper) из раздела **Artifacts**. Для скачивания может потребоваться вход в GitHub.
4. Полностью распакуйте архив, **не отделяйте `CLIPTORA.exe` от папки `_internal`**.

## FFmpeg и FFprobe

Если FFmpeg уже добавлен в `PATH`, ничего устанавливать не нужно. Иначе откройте Терминал Windows и выполните:

```powershell
winget install --id Gyan.FFmpeg --exact
```

Откройте новый терминал после установки. Альтернативно поместите `ffmpeg.exe` и `ffprobe.exe` в **`tools` рядом с `CLIPTORA.exe`** (создайте папку при необходимости). Проверка:

```powershell
ffmpeg -version
ffprobe -version
```

## Запуск

Дважды нажмите `CLIPTORA.exe` и откройте `http://127.0.0.1:8765`, если браузер не запустился автоматически. **Оставьте окно консоли открытым**, пока используете CLIPTORA. Записывайте видео в отдельную папку от самой программы.

Программа использует `%USERPROFILE%\CLIPTORA` для проекта, кэша и экспортов. Исходные записи не изменяются. Предыдущие проекты открываются без ручного переноса данных. Сервер доступен только локально — **не публикуйте порт 8765 в сети**.

## Ограничения сборки

- В архив включён Rust Core для сканирования файлов; он не ускоряет FFmpeg или распознавание речи.
- **Core:** библиотеки `faster-whisper` не включены. Для распознавания речи выберите версию AI или [запуск из исходников](INSTALL_RU.md).
- **AI:** Python и библиотеки `faster-whisper`, CTranslate2, PyAV и токенизации включены в архив; **веса моделей не включены**. На первом распознавании модель будет скачана из интернета. Размер архива AI существенно больше Core.
- Для диагностики AI запустите `CLIPTORA.exe --check-whisper` из консоли: успешная проверка подтверждает импорты и доступность CPU int8, **но не качество распознавания**. Настройка модели выполняется через интерфейс.
- AI использует CPU и может сильно нагружать память на длинных исходниках. Обработка видео идёт последовательно; регулировка количества потоков доступна в настройках.
- При проблемах с AI всегда можно использовать Core; они работают с той же локальной рабочей папкой, но без распознавания речи. Если включён режим речи, а библиотеки недоступны, CLIPTORA сообщит об этом в журнале.
- Отбор сцен основан на статистических признаках, а не на гарантированном распознавании шуток. Перед публикацией проверяйте монтаж вручную.
- Сборка собирается и проверяется на Windows в GitHub Actions. Полный стресс-тест на 250 ГБ не проводился.

Если EXE не запускается, откройте Issue и приложите текст ошибки **без личных путей, фрагментов видео и токенов**.


## Проверка настоящего распознавания речи (AI)

Из папки Portable можно запустить проверку на короткой записи с речью:

```powershell
.\CLIPTORA.exe --test-whisper "C:\Видео\пример.mp4" --whisper-test-model tiny --whisper-test-language ru
```

Первая проверка может скачать модель Whisper в пользовательский кэш. Для теста из CI используется `tiny.en` и английская синтезированная речь. Успех означает, что модель действительно распознала хотя бы один фрагмент со временными метками. Команда выводит **число сегментов и символов**, но не сам текст личной записи. Если речевых фрагментов нет, команда завершится с ошибкой.

Whisper в Core-редакции отсутствует. FFmpeg/FFprobe по-прежнему нужны для полноценного анализа и экспорта через интерфейс. Проверка модели не заменяет тестирования длительных записей.
