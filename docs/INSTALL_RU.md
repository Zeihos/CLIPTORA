# Установка и запуск CLIPTORA (Windows)

Актуально для **v0.1.18 Alpha**. Это исходный код с Windows-скриптами, **не готовый установщик `.exe`**.

## Перед запуском

1. Установите **Python 3.12** с [python.org](https://www.python.org/downloads/). Скрипты намеренно не выбирают Python 3.15: с ним ранее возникали проблемы совместимости бинарных зависимостей распознавания речи.
2. Распакуйте репозиторий **вне папки с исходными видео**.
3. Запустите `SETUP_WINDOWS.bat`. Он проверит Python 3.12 и наличие `ffmpeg`/`ffprobe`, при отсутствии FFmpeg попытается установить его через `winget` (если доступен).
4. Если FFmpeg устанавливался через `winget`, откройте новое окно терминала и **повторно запустите `SETUP_WINDOWS.bat`**. Пока FFmpeg/FFprobe не обнаружены, проверка завершается с ошибкой — это ожидаемо. Альтернатива — поместить `ffmpeg.exe` и `ffprobe.exe` в папку `tools` рядом с запускающими файлами.
5. Запустите `START_WINDOWS.bat`. Студия откроется по адресу <http://127.0.0.1:8765>. Окно консоли оставьте открытым.

Ручной запуск в терминале из папки программы: `py -3.12 server.py`.

## Обработка видео

1. Укажите папку с исходными записями, настройте CPU-потоки (по умолчанию 2; допустимо 1–8).
2. Нажмите «Сканировать», затем «Анализировать / продолжить».
3. Используйте «Сравнить 3 варианта» для безопасного предварительного выбора, либо «Создать подборку» (это заменяет текущий черновик).
4. Просмотрите сцены и при необходимости измените их границы, порядок и включение.
5. Соберите короткий предпросмотр (первые две минуты, 480p), проверьте звук и затем экспортируйте MP4.

**Важно:** обычная версия работает без Rust, Whisper и Ollama, но FFmpeg/FFprobe обязательны. Работа на библиотеке **250 ГБ пока не подтверждена** стресс-тестом.

## Дополнительные компоненты (необязательны)

- **Распознавание речи:** запустите `INSTALL_AI_WINDOWS.bat`. Он устанавливает `faster-whisper==1.2.1` и совместимый `av==18.1.0` для Python 3.12 и требует доступных бинарных пакетов. На первом распознавании может скачиваться языковая модель.
- **Оценка диалогов:** можно отдельно установить [Ollama](https://ollama.com/download/windows) и загрузить подходящую модель; по умолчанию для базовой работы она не нужна.
- **Rust Core:** установите [Rust](https://rustup.rs/), выполните `BUILD_RUST_WINDOWS.bat`. Он собирает `tools/cliptora-scanner.exe`. Rust только перечисляет файлы и их метаданные, а не выполняет монтаж или ИИ-анализ. Если Rust недоступен, программа перейдёт на Python.

## Файлы проекта и резервные копии

Данные новой установки хранятся в `%USERPROFILE%\CLIPTORA\`: `project.json`, `cache/`, `previews/`, `renders/`. Если остался старый проект Zeihos AI Montage Studio, приложение может использовать его прежнюю папку данных, чтобы не повредить существующие записи проекта.

Перед серьёзным редактированием копируйте `project.json` в отдельную папку. **Не размещайте папку CLIPTORA внутри папки с исходниками.** Исходное видео программа читает, а результат записывает отдельно.

## Частые проблемы

- **Не находит Python:** проверьте `py -3.12 --version`. Установка другого Python не заменяет 3.12 для Windows-скриптов.
- **Не найден FFmpeg:** проверьте `ffmpeg -version` и `ffprobe -version` в новом окне терминала или положите оба `.exe` в `tools/`.
- **Ошибка Whisper:** PyAV 19 несовместим с используемым faster-whisper 1.2.1. Запустите `INSTALL_AI_WINDOWS.bat` повторно для установки `av==18.1.0`. сначала проверьте базовую работу без ИИ, затем выполните `INSTALL_AI_WINDOWS.bat`. Не принуждайте pip собирать зависимости из исходников на несовместимом интерпретаторе.
- **Обработка прервана:** запустите CLIPTORA снова и нажмите «Анализировать / продолжить». Готовые файлы пропускаются; прерванный файл начинается заново.
- **Сцена не та:** автоматический балл — эвристика, а не вероятность смешного события. Исправьте границы клипа вручную.
- **Предпросмотр устарел:** при изменении черновика или настроек экспорта соберите его повторно.
- **Удалены или изменены исходники:** сделайте повторное сканирование; связанные клипы/эталоны могут быть инвалидированы.

## Конфиденциальность

Сервер доступен только с `127.0.0.1` и не должен быть открыт в интернет. Не загружайте на GitHub `project.json`, исходные записи, кэши, субтитры с личными разговорами, токены или файлы моделей. При сообщении об ошибках удаляйте личные пути и фрагменты записей.


**Не хочешь устанавливать Python?** См. [экспериментальную Portable-версию Windows](INSTALL_PORTABLE_RU.md). Для неё всё ещё нужен FFmpeg/FFprobe, распознавание речи в базовом EXE не включено.
