# Архитектура CLIPTORA

CLIPTORA — локальное приложение на **Python 3.12** с HTML/JavaScript-интерфейсом. Это не облачный сервис и не готовая Electron-программа. Основные модули пока находятся в корне репозитория для совместимости с действующими сценариями запуска.

## Поток обработки

```text
Исходные видео (только чтение)
          │
          ▼
  scanner_bridge.py ───────► Rust-сканер (необязателен)
          │                   только пути и метаданные файлов
          ▼
       engine.py ──────────► FFprobe / FFmpeg
          │                     звук / движение / декодирование
          ├────────────────► faster-whisper (необязательно)
          ├────────────────► локальный Ollama (необязательно)
          ▼
 highlight_signals.py + dialogue_context.py + climax_timing.py
          │
          ▼
 candidate_selection.py + plan_variants.py
          │
          ├────────────────► quality_benchmark.py (ручная разметка)
          ├────────────────► pacing.py + export_quality.py (эффекты)
          └────────────────► montage_preview.py + engine.py
                                        │
                                        ▼
                                 MP4 / SRT (локально)
```

`server.py` обслуживает `web/index.html` и JSON API на **`127.0.0.1:8765`**. Сервер не имеет механизма авторизации для работы из публичной сети; не открывай этот адрес через внешние туннели или проброс порта.

## Данные и совместимость

- **`project.json`** — локальное состояние библиотеки, очереди анализа, ручного монтажа, истории вариантов и эталонных меток. Это не SQLite-база.
- **`cache/`**, **`previews/`**, **`renders/`** — временные данные, предпросмотры и результаты. Они не должны попадать в Git.
- По умолчанию рабочая папка: `%USERPROFILE%\CLIPTORA\` (Windows) или `~/CLIPTORA` (другие ОС). Аргумент `server.py --work-dir` меняет путь.
- Для существующих проектов **Zeihos AI Montage Studio** может использоваться старая рабочая папка, чтобы не копировать большие кэши.
- Повторное сканирование сохраняет ID неизменённых файлов и их готовый анализ. Изменённые/удалённые записи инвалидируют связанные клипы и оценки.

## Производительность и ограничения

- Очередь обрабатывает **по одному видео** и сохраняет результаты на уровне файлов; прерванный файл может потребовать повторного анализа.
- Rust Core ускоряет только перечисление файлов. Анализ, Whisper, нарезка и экспорт выполняются Python/FFmpeg.
- Предпросмотр ограничен первыми **120 секундами в 480p**. Неполный экспорт не должен заменять последний завершённый результат.
- Precision/Recall/F1 отражают совпадение интервалов с ручными отметками, **не понимание шуток**.
- Производительность на библиотеке **250 ГБ не подтверждена** измеренным стресс-тестом.

Перенос модулей в пакет `src/cliptora/`, создание `.exe` или многодорожечного таймлайна потребуют отдельной миграции и проверок совместимости.
