# Безопасность CLIPTORA

CLIPTORA находится в стадии **Alpha** и предназначена для запуска на личном компьютере. Её локальный API **не рассчитан на подключение из интернета**.

## Основные рекомендации

- Не открывай порт **`8765`** в интернет и не проксируй его наружу. Интерфейс рассчитан на **`127.0.0.1`**.
- Используй актуальные сборки FFmpeg и обновляй операционную систему: вредоносные медиафайлы могут эксплуатировать уязвимости декодеров.
- Устанавливай Rust, Python, модели и внешние инструменты только из доверенных источников.
- Не публикуй в Issues и Pull Requests ключи, токены, приватные видео, стенограммы и пути с персональными данными.
- Делай резервные копии `project.json` перед крупными изменениями в библиотеке.

## Если обнаружена уязвимость

Не размещай рабочий эксплойт или конфиденциальные детали в публичном Issue. Если для репозитория доступна функция **Private vulnerability reporting** на GitHub, используй её. В противном случае сначала запроси у сопровождающего проекта безопасный способ приватной связи, не раскрывая технических деталей уязвимости публично.

В стадии Alpha **не установлен гарантированный срок реакции** на сообщения об уязвимостях. Изменения безопасности ориентируются прежде всего на актуальную ветку `main`.
