# Участие в разработке CLIPTORA

Спасибо за интерес к CLIPTORA! Это публичный **open-source проект в стадии Alpha**. Приветствуются исправления ошибок, небольшие полезные улучшения, тесты, понятные инструкции и отзывы по реальным игровым записям.

## С чего начать

1. Прочитай [README](README.md), [архитектуру](docs/ARCHITECTURE.md) и [инструкцию для разработчиков](docs/TESTING.md).
2. Проверь [открытые задачи](https://github.com/Zeihos/CLIPTORA/issues), чтобы не дублировать работу.
3. Для ошибки создай [Issue](https://github.com/Zeihos/CLIPTORA/issues/new/choose) с шагами воспроизведения. Для большой новой функции лучше сначала обсудить подход.
4. Сделай отдельную ветку от `main`, внеси изменения и открой Pull Request.
5. Расскажи **что изменено**, **зачем** и **как это проверялось**. Для изменений интерфейса приложи скриншоты без личных данных.

## Правила изменений

- Сохраняй работу под **Python 3.12** и совместимость с Windows-скриптами.
- Не ломай существующий `project.json`, историю монтажа и пути к исходным видеозаписям.
- Для новой логики добавляй тесты. Не выдавай пропущенные проверки за успешные.
- Не включай загрузку видео в облако, телеметрию и новые сетевые запросы без явного обоснования и согласования.
- Следи за лицензиями FFmpeg, моделей и библиотек; не копируй чужой закрытый код.
- Старайся писать понятные сообщения об ошибках **на русском** и не вводить новых зависимостей без необходимости.

## Как проверить изменения

```bash
python -m compileall -q .
python -m unittest discover -s tests -v
```

Если меняешь Rust-сканер:

```bash
cargo test --locked --manifest-path rust/scanner/Cargo.toml
cargo build --release --locked --manifest-path rust/scanner/Cargo.toml
```

GitHub Actions запускается на Windows и Ubuntu для Pull Request. Для изменений предпросмотра и экспорта желательно дополнительно проверить **реальный MP4** с FFmpeg.

## Безопасность данных

**Никогда не прикладывай** к Issue/PR исходные записи, личные разговоры, стенограммы, токены, `.env`, модели, файлы проекта или скриншоты с личными путями. Перед отправкой логов удали персональные данные. О потенциальных уязвимостях смотри [SECURITY.md](SECURITY.md).

Код распространяется под [MIT](LICENSE); сторонние зависимости и модели имеют собственные лицензии.
