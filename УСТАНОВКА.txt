CLIPTORA 0.1.3 ALPHA — установка Windows 10/11

Быстрый запуск:
1. Распакуйте архив в отдельную папку.
2. Запустите SETUP_WINDOWS.bat (Python 3.12 и FFmpeg).
3. Для распознавания речи при необходимости запустите INSTALL_AI_WINDOWS.bat.
4. Запустите START_WINDOWS.bat и откройте http://127.0.0.1:8765.
5. Выберите папку с видеозаписями, затем «Сканировать» → «Анализировать» → «Создать подборку».
6. Проверьте выбранные моменты и экспортируйте MP4.

ВАЖНО:
- Установщик использует Python 3.12; Python 3.15 не используется.
- faster-whisper требует первого скачивания модели при запуске распознавания.
- FFmpeg и FFprobe должны быть доступны через PATH или tools\.
- Данные новой установки: %USERPROFILE%\CLIPTORA.
- Если раньше использовалась Zeihos AI Montage Studio и там есть project.json, программа продолжит работать с прежней папкой, не копируя большие файлы.
- Исходные видео не изменяются; проект локальный, порт 8765 не публикуйте в Интернет.
- Альфа-анализ не гарантирует распознавания шуток и мемов. Отбор нужно проверять вручную.

Дополнительные инструкции: README.md.

Optional Rust Core: install Rust via https://rustup.rs/ and run BUILD_RUST_WINDOWS.bat.
Rust scans file metadata; AI and FFmpeg still run via Python. Without Rust everything works as before.
